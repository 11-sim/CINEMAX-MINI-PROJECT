
# Movie Ticket Booking System

## About the Project
The Movie Ticket Booking System is a Python-based application that simulates a theatre ticket booking counter. It allows users to view available movies, select show timings, choose seats and generate a booking ticket.

## Objectives
- To simulate a real-world movie ticket booking process.
- To display available movies, show timings and ticket prices.
- To allow users to select seats from a theatre layout.
- To prevent booking of seats that are already reserved.
- To generate a formatted ticket with the total amount.

## Features
- Displays four movies with multiple show timings.
- Shows ticket prices for each movie and show.
- Provides a 10 × 10 seat layout.
- Displays available and booked seats.
- Allows selection of multiple seats.
- Validates seat selections and prevents duplicate bookings.
- Generates a unique booking ID.
- Calculates 18% GST and the final ticket amount.
- Allows users to make another booking.

4. Run the following command:
